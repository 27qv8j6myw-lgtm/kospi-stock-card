- 요청: `GET /uapi/domestic-bond/v1/quotations/inquire-asking-price`
- TR_ID: 실전 `FHKBJ773401C0` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

장내채권현재가(호가) API입니다.
