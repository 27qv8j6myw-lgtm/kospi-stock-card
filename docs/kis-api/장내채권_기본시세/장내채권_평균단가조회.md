# 장내채권 평균단가조회

- 메뉴: [장내채권] 기본시세
- API ID: `국내주식-158` · 통신방식: REST
- 요청: `GET /uapi/domestic-bond/v1/quotations/avg-unit`
- TR_ID: 실전 `CTPF2005R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

장내채권 평균단가조회 API입니다. 
한국투자 HTS(eFriend Plus) > [7216] 채권 발행정보 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
