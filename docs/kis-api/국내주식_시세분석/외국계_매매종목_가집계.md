- 메뉴: [국내주식] 시세분석
- API ID: `국내주식-161` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/frgnmem-trade-estimate`
- TR_ID: 실전 `FHKST644100C0` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

외국계 매매종목 가집계 API입니다.
한국투자 HTS(eFriend Plus) > [0430] 외국계 매매종목 가집계 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
