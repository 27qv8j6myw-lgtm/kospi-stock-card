# 국내주식 매물대/거래비중

- 메뉴: [국내주식] 시세분석
- API ID: `국내주식-196` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/pbar-tratio`
- TR_ID: 실전 `FHPST01130000` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내주식 매물대/거래비중 API입니다.
한국투자 HTS(eFriend Plus) > [0113] 당일가격대별 매물대 화면의 데이터 중 일부를 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | FHPST01130000 |
| tr_cont | 연속 거래 여부 | string | N | 1 | tr_cont를 이용한 다음조회 불가 API |
