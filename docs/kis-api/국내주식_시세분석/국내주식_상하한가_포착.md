# 국내주식 상하한가 포착

- 메뉴: [국내주식] 시세분석
- API ID: `국내주식-190` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/capture-uplowprice`
- TR_ID: 실전 `FHKST130000C0` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내주식 상하한가 포착 API입니다.
한국투자 HTS(eFriend Plus) > [0917] 실시간 상하한가 포착 화면 의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
