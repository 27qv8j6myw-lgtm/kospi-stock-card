# 선물옵션 실시간체결통보

- 메뉴: [국내선물옵션] 실시간시세
- API ID: `실시간-012` · 통신방식: WEBSOCKET
- 요청: `POST /tryitout/H0IFCNI0`
- TR_ID: 실전 `H0IFCNI0` · 모의 `H0IFCNI9`
- 도메인: 실전 ws://ops.koreainvestment.com:21000 · 모의 ws://ops.koreainvestment.com:31000

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| approval_key | 웹소켓접속키 | string | Y | 36 | 실시간 (웹소켓) 접속키 발급 API(/oauth2/Approval)를 사용하여 발급받은 웹소켓 접속키 |
| tr_type | 등록/해제 | string | Y | 1 | 1: 등록, 2:해제 |

## Request Body

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 7 | [실전투자]<br>H0IFCNI0 : 실시간 선물옵션 체결통보<br><br>[모의투자]<br>H0IFCNI9 : 실시간 선물옵션 체결통보 |
| tr_key | 코드 | string | Y | 6 | HTS ID |

```json
         }
}
```
