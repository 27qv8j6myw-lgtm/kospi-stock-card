# 해외주식 체결추이

- 메뉴: [해외주식] 기본시세
- API ID: `해외주식-037` · 통신방식: REST
- 요청: `GET /uapi/overseas-price/v1/quotations/inquire-ccnl`
- TR_ID: 실전 `HHDFS76200300` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

해외주식 체결추이 API입니다.
한국투자 HTS(eFriend Plus) > [7625] 해외주식 체결추이 화면 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
