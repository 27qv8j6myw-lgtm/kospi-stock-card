# 해외결제일자조회

- 메뉴: [해외주식] 기본시세
- API ID: `해외주식-017` · 통신방식: REST
- 요청: `GET /uapi/overseas-stock/v1/quotations/countries-holiday`
- TR_ID: 실전 `CTOS5011R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

해외결제일자조회 API입니다.

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | CTOS5011R |
| tr_cont | 연속 거래 여부 | string | N | 1 | tr_cont를 이용한 다음조회 불가 API |

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
