# 해외선물옵션 실시간주문내역통보

- 메뉴: [해외선물옵션]실시간시세
- API ID: `실시간-019` · 통신방식: WEBSOCKET
- 요청: `POST /tryitout/HDFFF1C0`
- TR_ID: 실전 `HDFFF1C0` · 모의 `-`
- 도메인: 실전 ws://ops.koreainvestment.com:21000 · 모의 -

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| approval_key | 웹소켓접속키 | string | Y | 36 | 실시간 (웹소켓) 접속키 발급 API(/oauth2/Approval)를 사용하여 발급받은 웹소켓 접속키 |
| tr_type | 등록/해제 | string | Y | 1 | "1: 등록, 2:해제" |

| Element | 한글명 | Type | 필수 | 길이 | 설명 |

| tr_id | 거래ID | string | Y | 7 | HDFFF1C0 |
