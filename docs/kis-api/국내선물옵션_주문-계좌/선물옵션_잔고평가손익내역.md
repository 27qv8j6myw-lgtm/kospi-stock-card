- 메뉴: [국내선물옵션] 주문/계좌
- API ID: `v1_국내선물-015` · 통신방식: REST
- 요청: `GET /uapi/domestic-futureoption/v1/trading/inquire-balance-valuation-pl`
- TR_ID: 실전 `CTFO6159R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

선물옵션 잔고평가손익내역 API입니다.

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | CTFO6159R |
