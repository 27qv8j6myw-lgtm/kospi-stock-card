# 선물옵션 잔고현황

- 메뉴: [국내선물옵션] 주문/계좌
- API ID: `v1_국내선물-004` · 통신방식: REST
- 요청: `GET /uapi/domestic-futureoption/v1/trading/inquire-balance`
- TR_ID: 실전 `CTFO6118R` · 모의 `VTFO6118R`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 https://openapivts.koreainvestment.com:29443

## 개요

선물옵션 잔고현황 API입니다. 한 번의 호출에 최대 20건까지 확인 가능하며, 이후의 값은 연속조회를 통해 확인하실 수 있습니다.

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | [실전투자]<br>CTFO6118R : 선물 옵션 잔고 현황<br><br>[모의투자] <br>VTFO6118R : 선물 옵션 잔고 현황 |
| tr_cont | 연속 거래 여부 | string | N | 1 | tr_cont를 이용한 다음조회 불가 API |
