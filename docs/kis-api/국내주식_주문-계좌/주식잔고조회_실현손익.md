# 주식잔고조회_실현손익

- 메뉴: [국내주식] 주문/계좌
- API ID: `v1_국내주식-041` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/trading/inquire-balance-rlz-pl`
- TR_ID: 실전 `TTTC8494R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

주식잔고조회_실현손익 API입니다.
한국투자 HTS(eFriend Plus) [0800] 국내 체결기준잔고 화면을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
(참고: 포럼 - 공지사항 - 신규 API 추가 안내(주식잔고조회_실현손익 외 1건))

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | TTTC8494R |
