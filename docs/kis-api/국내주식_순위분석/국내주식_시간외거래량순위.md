# 국내주식 시간외거래량순위

- 메뉴: [국내주식] 순위분석
- API ID: `국내주식-139` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/ranking/overtime-volume`
- TR_ID: 실전 `FHPST02350000` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내주식 시간외거래량순위 API입니다. 
한국투자 HTS(eFriend Plus) > [0235] 시간외 거래량순위 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
최대 30건 확인 가능하며, 다음 조회가 불가합니다.

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | FHPST02350000 |
| tr_cont | 연속 거래 여부 | string | N | 1 | tr_cont를 이용한 다음조회 불가 API |

| FID_COND_SCR_DIV_CODE | 조건 화면 분류 코드 | string | Y | 5 | Unique key(20235) |

| FID_INPUT_PRICE_1 | 입력 가격1 | string | Y | 12 | 가격 ~ |
| FID_INPUT_PRICE_2 | 입력 가격2 | string | Y | 12 | ~ 가격 |
| FID_VOL_CNT | 거래량 수 | string | Y | 12 | 거래량 ~ |
