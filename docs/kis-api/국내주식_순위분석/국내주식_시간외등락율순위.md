# 국내주식 시간외등락율순위

- 메뉴: [국내주식] 순위분석
- API ID: `국내주식-138` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/ranking/overtime-fluctuation`
- TR_ID: 실전 `FHPST02340000` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내주식 시간외등락율순위 API입니다. 
한국투자 HTS(eFriend Plus) > [0234] 시간외 등락률순위 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
최대 30건 확인 가능하며, 다음 조회가 불가합니다.
