# 국내업종 시간별지수(초)

- 메뉴: [국내주식] 업종/기타
- API ID: `국내주식-064` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/inquire-index-tickprice`
- TR_ID: 실전 `FHPUP02110100` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내업종 시간별지수(초) API입니다. 
한국투자 HTS(eFriend Plus) > [0211] 업종 시간별지수 화면에서 우측 '10초' 선택 시의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
