- 메뉴: [국내주식] 업종/기타
- API ID: `v1_국내주식-063` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/inquire-index-price`
- TR_ID: 실전 `FHPUP02100000` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -
- 이 프로젝트에서 사용 중 (`server/` 에서 TR_ID 검색)

## 개요

국내업종 현재지수 API입니다.
