# 국내선물 기초자산 시세

- 메뉴: [국내선물옵션] 기본시세
- API ID: `국내선물-021` · 통신방식: REST
- 요청: `GET /uapi/domestic-futureoption/v1/quotations/display-board-top`
- TR_ID: 실전 `FHPIF05030000` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내선물 기초자산 시세 API입니다. 
한국투자 HTS(eFriend Plus) > [0503] 선물옵션 종합시세(Ⅰ) 화면의 "상단 바" 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
