# 해외선물옵션 기간계좌거래내역

- 메뉴: [해외선물옵션] 주문/계좌
- API ID: `해외선물-014` · 통신방식: REST
- 요청: `GET /uapi/overseas-futureoption/v1/trading/inquire-period-trans`
- TR_ID: 실전 `OTFM3114R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

해외선물옵션 기간계좌거래내역 API입니다.

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | OTFM3114R |
| tr_cont | 연속 거래 여부 | string | N | 1 | 공백 : 초기 조회<br>N : 다음 데이터 조회 (output header의 tr_cont가 M일 경우) |
