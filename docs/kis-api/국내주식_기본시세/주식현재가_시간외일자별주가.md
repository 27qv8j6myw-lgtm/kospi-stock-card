- 메뉴: [국내주식] 기본시세
- API ID: `v1_국내주식-026` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/inquire-daily-overtimeprice`
- TR_ID: 실전 `FHPST02320000` · 모의 `FHPST02320000`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 https://openapivts.koreainvestment.com:29443

## 개요

주식현재가 시간외일자별주가 API입니다.  (최근일 30건만 조회 가능)
