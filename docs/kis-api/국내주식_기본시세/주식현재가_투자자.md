# 주식현재가 투자자

- 메뉴: [국내주식] 기본시세
- API ID: `v1_국내주식-012` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/quotations/inquire-investor`
- TR_ID: 실전 `FHKST01010900` · 모의 `FHKST01010900`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 https://openapivts.koreainvestment.com:29443
- 이 프로젝트에서 사용 중 (`server/` 에서 TR_ID 검색)

## 개요

주식현재가 투자자 API입니다. 개인, 외국인, 기관 등 투자 정보를 확인할 수 있습니다.

[유의사항]
- 외국인은 외국인(외국인투자등록 고유번호가 있는 경우)+기타 외국인을 지칭합니다.
- 당일 데이터는 장 종료 후 제공됩니다.
