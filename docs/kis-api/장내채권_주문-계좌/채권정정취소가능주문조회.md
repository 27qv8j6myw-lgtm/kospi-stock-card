# 채권정정취소가능주문조회

- 메뉴: [장내채권] 주문/계좌
- API ID: `국내주식-126` · 통신방식: REST
- 요청: `GET /uapi/domestic-bond/v1/trading/inquire-psbl-rvsecncl`
- TR_ID: 실전 `CTSC8035R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

채권정정취소가능주문조회 API입니다. 
정정취소가능한 채권주문 목록을 확인할 수 있습니다.

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | CTSC8035R |
| tr_cont | 연속 거래 여부 | string | N | 1 | 공백 : 초기 조회<br>N : 다음 데이터 조회 (output header의 tr_cont가 M일 경우) |

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
