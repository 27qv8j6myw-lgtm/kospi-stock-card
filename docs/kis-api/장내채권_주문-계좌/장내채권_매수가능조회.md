# 장내채권 매수가능조회

- 메뉴: [장내채권] 주문/계좌
- API ID: `국내주식-199` · 통신방식: REST
- 요청: `GET /uapi/domestic-bond/v1/trading/inquire-psbl-order`
- TR_ID: 실전 `TTTC8910R` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

장내채권 매수가능조회 API입니다. 
한국투자 HTS(eFriend Plus) > [0978] 장내채권주문 화면의 "왼쪽 하단 증거금 사용가능 내역 / 주문가능금액 및 수량" 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다. 

※ (중요) 채권의 경우 주식과 달리, 매수가능수량(buy_psbl_qty) = 매수가능금액(buy_psbl_amt) / 채권주문단가2(bond_ord_unpr2) * 10 인 점 유의하시기 바랍니다.

| Element | 한글명 | Type | 필수 | 길이 | 설명 |

| tr_cont | 연속 거래 여부 | string | N | 1 | tr_cont를 이용한 다음조회 불가 API |
