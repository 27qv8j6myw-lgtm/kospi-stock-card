# 장내채권 매도주문

- 메뉴: [장내채권] 주문/계좌
- API ID: `국내주식-123` · 통신방식: REST
- 요청: `POST /uapi/domestic-bond/v1/trading/sell`
- TR_ID: 실전 `TTTC0958U` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

장내채권 매도주문 API입니다. 
한국투자 HTS(eFriend Plus) > [0978] 장내채권주문 '채권매도' 탭의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

| Element | 한글명 | Type | 필수 | 길이 | 설명 |
|---|---|---|---|---|---|
| tr_id | 거래ID | string | Y | 13 | TTTC0958U |
| tr_cont | 연속 거래 여부 | string | N | 1 | tr_cont를 이용한 다음조회 불가 API |
