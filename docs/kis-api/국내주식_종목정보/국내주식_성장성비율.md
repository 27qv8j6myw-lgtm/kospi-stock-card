# 국내주식 성장성비율

- 메뉴: [국내주식] 종목정보
- API ID: `v1_국내주식-085` · 통신방식: REST
- 요청: `GET /uapi/domestic-stock/v1/finance/growth-ratio`
- TR_ID: 실전 `FHKST66430800` · 모의 `-`
- 도메인: 실전 https://openapi.koreainvestment.com:9443 · 모의 -

## 개요

국내주식 성장성비율 API입니다.
한국투자 HTS(eFriend Plus) > [0635] 재무분석종합 화면의 하단 '7.성장성비율' 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
